# Edelweiss-Cumple 👑✨

Invitaciones digitales interactivas para el 4º cumpleaños de Edelweiss (15 de noviembre).

Temática: Reino Encantado de Princesas y Príncipes de Disney (inclusivo).

## Versiones disponibles

- **v1/** → Portal al Reino Encantado (Glassmorphism + partículas interactivas)
- **v2/** → El Manuscrito del Rey (Scroll cinematográfico con parallax)

## Cómo completar las fotos

Las invitaciones referencian estas fotos (renombra tus archivos así y súbelas a la carpeta correspondiente):

**Para v1/** (sube estos dos):
- `Photo_20261111-094353.jpg` (héroe)
- `Photo_20261111-094353_4.jpg` (medallón)

**Para v2/** (sube estos cuatro):
- `Photo_20261111-094353_2.jpg`
- `Photo_20261111-094353_3.jpg`
- `Photo_20261111-094353_5.jpg`
- `Photo_20261111-094353_6.jpg`

Puedes arrastrar y soltar los archivos directamente en la carpeta en GitHub (interfaz web). Los nombres deben coincidir exactamente.

## Publicación con GitHub Pages (1 paso)

1. Ve a **Settings → Pages**.
2. En **Source**, selecciona la rama `main` y la carpeta `/ (root)`.
3. Guarda. En 1-2 minutos tendrás:
   - Menú: `https://manu-alvarez.github.io/Edelweiss-Cumple/`
   - V1: `https://manu-alvarez.github.io/Edelweiss-Cumple/v1/`
   - V2: `https://manu-alvarez.github.io/Edelweiss-Cumple/v2/`

## Personalización rápida

En cada `index.html` busca y sustituye:
- `URL_GOOGLE_MAPS` → enlace de Google Maps de la casa.
- `NUMERO_WHATSAPP` → número con código de país (ej: 34600000000).

## Añadir más versiones

1. Crea una nueva carpeta, por ejemplo `v3/`.
2. Añade un `index.html` dentro.
3. Actualiza el `index.html` de la raíz para incluir el enlace.
4. Commit y push.
