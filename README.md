# Edelweiss-Cumple 👑✨

Invitaciones digitales interactivas para el 4º cumpleaños de Edelweiss (15 de noviembre).

Temática: Reino Encantado de Princesas y Príncipes de Disney (inclusivo).

## Versiones disponibles

- **v1/** → Portal al Reino Encantado (Glassmorphism + partículas interactivas)
- **v2/** → El Manuscrito del Rey (Scroll cinematográfico con parallax)

Cada carpeta (`v1/`, `v2/`, etc.) contiene su propio `index.html` autocontenido (imágenes embebidas en base64 para máxima portabilidad).

## Cómo añadir una nueva versión

1. Crea una nueva carpeta, por ejemplo `v3/`.
2. Añade un `index.html` dentro de ella.
3. Actualiza el `index.html` de la raíz para incluir un enlace a `v3/`.
4. Haz commit y push.

## Publicación con GitHub Pages

1. Ve a **Settings → Pages**.
2. En **Source**, selecciona la rama `main` y la carpeta `/ (root)`.
3. Guarda. En unos minutos tendrás:
   - Menú principal: `https://manu-alvarez.github.io/Edelweiss-Cumple/`
   - Versión 1: `https://manu-alvarez.github.io/Edelweiss-Cumple/v1/`
   - Versión 2: `https://manu-alvarez.github.io/Edelweiss-Cumple/v2/`

## Personalización

En cada `index.html` busca y sustituye:
- `URL_GOOGLE_MAPS` → enlace de Google Maps de la casa.
- `NUMERO_WHATSAPP` → número con código de país (ej: 34600000000).
